# Data Dictionary — Kalimantan Fire Situation Monitor (Phase 1)

This document provides complete technical metadata, schema definitions, coordinate reference systems, and value domains for all data layers generated by the **Kalimantan Fire Situation Monitor**.

---

## 1. General Spatial & Temporal Standards

| Parameter | Standard | Description |
|---|---|---|
| **Coordinate Reference System (CRS)** | `EPSG:4326` (WGS 84) | Geographic coordinates in decimal degrees |
| **Temporal Standard** | UTC (Coordinated Universal Time) | Standardized time without daylight saving adjustments |
| **Date Format** | `YYYY-MM-DD` (ISO 8601) | e.g., `2026-08-20` |
| **Timestamp Format** | `YYYY-MM-DDTHH:MM:SSZ` (ISO 8601) | UTC timestamp representation |

---

## 2. VIIRS Source Bands (Earth Engine ImageCollection)

Collections:
- `NASA/LANCE/SNPP_VIIRS/C2` (Suomi NPP)
- `NASA/LANCE/NOAA20_VIIRS/C2` (NOAA-20)

| Band Name | Data Type | Units | Valid Range | Description |
|---|---|---|---|---|
| `bright_ti4` | Float32 | Kelvin (K) | 200.0 – 380.0 | VIIRS I-4 channel brightness temperature (3.75 µm mid-infrared). Primary band for detecting high-temperature thermal anomalies. |
| `bright_ti5` | Float32 | Kelvin (K) | 150.0 – 350.0 | VIIRS I-5 channel brightness temperature (11.0 µm thermal infrared). Used for background characterization and cloud filtering. |
| `confidence` | UInt8 | Categorical Index | 0, 1, 2 | Algorithm detection confidence score.<br>• `0`: Low confidence (often edge-of-swath or weak anomaly)<br>• `1`: Nominal confidence (standard detection)<br>• `2`: High confidence (saturated pixel / intense anomaly) |
| `frp` | Float32 | Megawatts (MW) | 0.0 – 10000.0 | Fire Radiative Power. Estimated instantaneous radiative energy output of the thermal anomaly pixel. |

---

## 3. Raw Detections Export Schema (`raw/kalimantan_fires_all_{window}.csv`)

Contains **ALL** valid active-fire detections extracted within the temporal window prior to confidence filtering.

| Column | Type | Units / Format | Nullable | Description |
|---|---|---|---|---|
| `latitude` | Float64 | Decimal Degrees | No | Latitude of the 375 m pixel centroid (EPSG:4326). |
| `longitude` | Float64 | Decimal Degrees | No | Longitude of the 375 m pixel centroid (EPSG:4326). |
| `bright_ti4` | Float64 | Kelvin (K) | Yes | VIIRS I-4 brightness temperature. |
| `bright_ti5` | Float64 | Kelvin (K) | Yes | VIIRS I-5 brightness temperature. |
| `confidence` | Int64 | Categorical (0, 1, 2) | No | Detection confidence indicator. |
| `frp` | Float64 | Megawatts (MW) | Yes | Fire Radiative Power. |
| `acq_date` | String | `YYYY-MM-DD` | No | Satellite acquisition date (UTC). |
| `satellite` | String | String | No | Sensor platform: `'SNPP'` or `'NOAA-20'`. |
| `province` | String | String | No | Assigned Indonesian Province name (ADM1) via spatial join. `'Unassigned'` if outside polygons. |
| `regency` | String | String | No | Assigned Indonesian Regency / Kabupaten / Kota name (ADM2). `'Unassigned'` if outside polygons. |

---

## 4. Operational Detections Export Schema (`processed/kalimantan_fires_operational_{window}.csv` & `.geojson`)

Contains **OPERATIONAL** active-fire detections (nominal + high confidence, `confidence >= 1`), enriched with spatial cluster identifiers.

| Column / Property | Type | Units / Format | Nullable | Description |
|---|---|---|---|---|
| `latitude` | Float64 | Decimal Degrees | No | Centroid latitude (WGS 84). |
| `longitude` | Float64 | Decimal Degrees | No | Centroid longitude (WGS 84). |
| `bright_ti4` | Float64 | Kelvin (K) | Yes | VIIRS I-4 brightness temperature. |
| `bright_ti5` | Float64 | Kelvin (K) | Yes | VIIRS I-5 brightness temperature. |
| `confidence` | Int64 | Categorical (1, 2) | No | Operational confidence score (`1`=Nominal, `2`=High). |
| `frp` | Float64 | Megawatts (MW) | Yes | Fire Radiative Power. |
| `acq_date` | String | `YYYY-MM-DD` | No | Satellite acquisition date (UTC). |
| `satellite` | String | String | No | Satellite platform (`'SNPP'` or `'NOAA-20'`). |
| `province` | String | String | No | Province name (ADM1). |
| `regency` | String | String | No | Regency / City name (ADM2). |
| `cluster_id` | Int64 | Integer | No | DBSCAN cluster ID. `-1` denotes spatial noise (unclustered detection). Non-negative integers (`0, 1, 2, ...`) denote cluster membership. |
| `geometry` | Point | GeoJSON Point | No | `[longitude, latitude]` in EPSG:4326 (GeoJSON export only). |
